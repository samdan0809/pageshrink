PageShrink 页面小窗 · 设置

点图标把当前页面收进一个无边框小窗；改动即时生效，不需要重新加载扩展。

缩小方式

Chrome 禁止把标签页搬进无边框窗口，所以纯净小窗只能重新加载页面。

小窗尺寸

这是浏览器窗口的真实尺寸，页面按正常字号在这个小窗里重新排版。

多显示器时会停在「当前窗口所在那块屏」的工作区，不会甩到副屏外。
注意：「保留页面状态」模式下 Chrome 对带标签栏的窗口有约 500px 最小宽度硬限制，420 会被自动放大到 500；「纯净小窗」没有这个限制，竖版 420×640 正好。

原窗口只剩一个标签时最小化它否则桌面上会留一个空的大窗口；还原时自动恢复

窗口标题

小窗期间替换浏览器标题栏（和标签页）上的名字，还原后自动改回去。

可用占位符：{title} 原网页标题、{host} 域名。 例如填 {host} · 文档 会显示成 example.com · 文档。

网页自己改标题（SPA 路由、未读数、倒计时）时会自动重新套上你的标题。

怎么用

  1. 在普通浏览器窗口里点工具栏的 PageShrink 图标。
  2. 页面会变成一个独立的小窗口停在屏幕角落，可以拖动、可以拉边缘改大小。
  3. 鼠标移出这个小窗 → 网页被遮罩盖住；移回来 → 立刻恢复，正常滚动点击。
  4. 小窗右上角的 还原 按钮把页面放回原来的窗口，并关掉小窗。
  5. 也可以在原来的大窗口里再点一次图标来还原。
  6. 多个窗口各点一次，会各自生成独立小窗，最多 8 个。

纯净小窗：没有标签栏和地址栏，但页面会重新加载一次（已尽量把滚动位置带过去，未提交的表单、SPA 内部状态会丢）。 保留页面状态：不重新加载、状态完整，但标签栏和地址栏还在。这是 Chrome 的限制，扩展无法把标签页搬进无边框窗口。

若用于本地 file:// 页面，请在扩展详情页开启「允许访问文件网址」；chrome:// 等浏览器自身页面无法注入脚本。

安装

  1. 地址栏打开 chrome://extensions，右上角开启开发者模式。
  2. 点加载已解压的扩展程序，选择 pageshrink 文件夹。
  3. 建议把图标固定到工具栏，之后一键切换。
